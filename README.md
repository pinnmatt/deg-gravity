## What is DEG?

Discrete Emergent Gravity (DEG) is a theoretical physics research programme investigating whether spacetime, gravity, and part of the Standard Model's structure can be derived from a single Hamiltonian constraint:

```
H = Σ_n [ p_n² / 2m  −  (α/2) a_n² ] = 0
```

Spacetime consists of *N* discrete Planck-scale atoms each carrying *g* = 442 internal quantum states. *g* = 442 follows from the requirement that SU(21)×U(1) embeds the Standard Model, given the adjoint-plus-doublet representation choice.

Three calibrated inputs are used: α_exp^cosm (cosmological constant magnitude), ε_α and ε_β (Higgs EWSB parameters). Open problems are stated plainly.

## Selected open problems

- **κ_V = 0.432**: 14.2σ from LHC at tree level; analytical ceiling 5.1σ; requires DEG-L Group C
- **α_exp^cosm**: calibrated input; multiple derivation routes ruled out; theoretical breakthrough required
- **Atomic spacing a**: no derivation; RG route gives wrong sign
- **Five-to-three generation reduction**: branching rule gives 5 copies, not 3
- **Sterile neutrino / leptogenesis**: seesaw misses by ~13 orders; leptogenesis 5 orders short; Affleck-Dine residual factor ~6 is fit, not derived
- **Bekenstein-Hawking coefficient**: imported, not derived from g=442
